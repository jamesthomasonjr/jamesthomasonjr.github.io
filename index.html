  • Vic — Visual Context

    in_development

    A headless agent harness and context editor inspired by Vim and Neovim.

    Vic explores what a Vim-like environment could look like for the agent age: context as an editable developer resource, a small headless core, semantic commands and actions, protocol-separated interfaces, pluggable providers, and extensibility built around agent workflows rather than text files.

    Repository private // public release planned

About

I've spent my career building full-stack products, developer platforms, infrastructure, and tools. More recently, my work has moved toward agentic software — not only using AI to build software, but building the systems around agents that make them more useful to developers and teams.

Trajectory

Current Aug 2026 — Present
Founding Engineer (Independent), Stations.dev — Building an agent-native work execution platform for humans and autonomous agents.
Previous Jun 2022 — Aug 2026
Software Development Engineer II, Amazon — Built AI workflow platforms, experimentation systems, cloud infrastructure, and developer tooling.

Core engineering philosophy: Strip friction away from cognitive work. Reliable engineering systems aren't built through opaque autonomous magic; they need explicit state, clear boundaries, observable behavior, and good ergonomics so humans and agents can work together effectively.
